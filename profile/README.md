# Miners Online

**Miners Online** is a small, open-source Minecraft server project maintained by a single developer in the UK since 2017. It is a personal project for experimenting with server development, testing new features, and sharing code openly with anyone interested in learning or contributing.

## Features in Development

* **Custom Features:** Experimental mechanics, including the server’s signature "Golf" mini-game.
* **Open Source:** The majority of server code is public and available for study, modification, or contribution.

## Get Involved

You can participate in the project in several ways:

* Review or contribute code via the [GitHub repository](https://github.com/miners-online)
* Discuss ideas or suggest improvements on [GitHub Discussions](https://github.com/orgs/miners-online/discussions)
* Report issues using [GitHub Issues](https://github.com/miners-online/.github/issues)

Miners Online exists as a **personal, open-ended project** to explore Minecraft server development and maintain a space for experimentation and learning.
