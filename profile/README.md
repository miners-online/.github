# Miners Online

**Miners Online** is a small, open-contribution **(not open source!)** Minecraft server project maintained by a single developer in the UK ongoining since 2017. It is a personal project for experimenting with server development, testing new features, and sharing code openly with anyone interested in learning or contributing.

## Key repoistories and information

* [**`web-monorepo`**](https://github.com/miners-online/web-monorepo): The combined home for all our web services
* [**`monoreop`**](https://github.com/miners-online/monorepo): All game code and supporting APIs
* [**`infra`**](https://github.com/miners-online/infra): Infrastructure-as-Code for managing Miners Online server infrastructure on Kubernetes, currentlly WIP
* [**Project roadmap**](https://github.com/orgs/miners-online/projects/2): Our complete project development roadmap

## Get Involved

You can participate in the project in several ways:

* Review or contribute code via the [GitHub repository](https://github.com/miners-online)
* Discuss ideas or suggest improvements on [GitHub Discussions](https://github.com/orgs/miners-online/discussions)
* Report issues on the relevant repoistory

Miners Online exists as a **personal, open-ended project** to explore Minecraft server development and maintain a space for experimentation and learning.
